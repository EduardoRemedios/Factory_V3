# Raw Brief - V3 Mission Formation Skills Plan

## User Request
Create the Phase 4.5 planning pack for non-executing Factory V3 mission-formation skills.

## Background
Factory V3 has captured a strategic direction that long-running autonomy depends on mission quality. The repository now includes:
- `docs/Factory/v3/MISSION_FORMATION_DIRECTION.md`
- `docs/Factory/v3/CODEX_SDK_ORCHESTRATION_DIRECTION.md`
- `docs/Factory/v3/ROADMAP_TO_FULL_VISION.md` Phase 4.5

The next move is to design the skill or skills that support discovery, challenge, and candidate mission-contract creation before any long-running execution mission begins.

## Execution Mode
PLANNING_ONLY

## Objective
Prepare a Factory planning pack that governs a future implementation run to design and create non-executing mission-formation skills.

## Candidate Skill Scope
- `factory-mission-formation`: Socratic discovery, problem framing, assumption testing, option design, execution-readiness assessment, and candidate mission-envelope creation.
- `factory-challenge-mission`: red-team review of discovery output, weak assumptions, authority gaps, over-scoping, verification gaps, fallback triggers, and overnight-run failure modes.

Skill names are directional and may be changed by the planning pack.

## Required Planning Outputs
The pack should define:
- exact target files for a future skill implementation,
- whether one skill or two skills should be created first,
- trigger descriptions and non-trigger boundaries,
- non-authority rules,
- required skill outputs,
- trial plan with at least three briefs,
- verification and advisory checks,
- V2 fallback preservation checks,
- explicit prohibition on execution authority.

## Non-Goals
- Do not create or edit the skill files in this planning run.
- Do not approve a new V3 operational profile.
- Do not approve non-coding execution missions.
- Do not approve Codex SDK/MCP orchestration implementation.
- Do not approve runtime authority, production actions, default-mode behavior, required gates, telemetry enforcement, governance routing, proof, lease enforcement, or V2 scaffolding removal.

## Human Approval Requirement
Future skill implementation requires separate human Go after this planning pack passes review.
