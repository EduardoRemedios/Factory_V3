## Version
v0.1

## Change Log
- v0.1 (2026-06-05): Initial Stage E premortem.

## Failure Scenarios
1. The future skill creates polished mission contracts that users treat as execution approval.
   - Mitigation: candidate-only labels, human Go requirement, and verification of non-authority wording.
2. The future skill asks many questions but does not converge.
   - Mitigation: require execution-readiness assessment and recommended route.
3. The future skill suppresses V2 fallback.
   - Mitigation: trial at least one V2/heavier-planning case and require fallback preservation review.
4. SDK/MCP orchestration is implemented too early.
   - Mitigation: explicit no-go boundary and later read-only spike.
5. Skill descriptions trigger on ordinary bounded tasks.
   - Mitigation: define precise trigger/non-trigger language and trial over-triggering.
