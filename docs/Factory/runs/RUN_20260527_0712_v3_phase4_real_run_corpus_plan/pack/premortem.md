## Version
v0.1

## Change Log
- v0.1 (2026-05-27): Initial Stage E premortem.

## Failure Scenarios
- PM1 Critical: The plan is treated as permission to run real missions immediately. Mitigation: require later explicit approval for each evidence mission.
- PM2 Critical: Harness profiles become universal capability scores. Mitigation: bind every observation to harness, model when known, repo, tools, mission profile, date, and evidence.
- PM3 Critical: Real-run evidence is used for routing or reduced governance. Mitigation: state that Phase 5 remains unapproved.
- PM4 High: Optional telemetry becomes routine or required. Mitigation: require separate approval and keep payloads summary-only and non-blocking.
- PM5 High: Corpus captures only happy paths. Mitigation: track the missing natural halted, fallback, or clarification-heavy case as an unresolved gap.
- PM6 High: FP/FN classifications lack human adjudication. Mitigation: require reviewer classification fields.
- PM7 Medium: Evidence templates collect sensitive data. Mitigation: preserve data-minimization exclusions.
- PM8 Medium: V2 fallback weakens. Mitigation: require fallback trigger fields and non-deprecation language.
