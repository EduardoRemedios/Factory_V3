## MS-03 Candidate Selection Rules
- Objective: Define one or two candidate selection rules without naming live work as approved.
- Inputs: `V3-OP-001` boundaries and V2 fallback rules.

- Entry criteria: MS-01 complete.
- Exit criteria: actual mission execution remains blocked pending later approval.
- Stop or go gate: stop if candidates include auth, payment, compliance, infrastructure, runtime, or deployment work.

- Objective: Verify future artifacts remain advisory and scoped.
- Inputs: outputs from MS-01 through MS-03.
- Outputs: command results and manual scope review.

- Exit criteria: all future checks pass or failures are halted.
- Stop or go gate: stop on router, enforcement, required-gate, telemetry-completeness, runtime-authority, proof, lease, default-mode, promotion, or V2-removal drift.
