# POC Vision

## Version
v0.1

## Status
Research-only and non-enforcing until a separate POC mission is approved.

## Product Vision
Build a private proof-of-concept application that demonstrates Factory V3 can be used operationally with Codex.

Candidate app:

```text
Personal health and fitness tracker.
```

## Operational Proof Vision
The POC is not only an app test. It is a V3 operations test.

The proof succeeds if V3 with Codex can:
- shape the app vision,
- lock constraints,
- plan bounded missions,
- implement the app,
- run verification,
- privately deploy the app,
- record evidence,
- recover or halt correctly,
- produce a defensible readiness decision,
- do all of that without Factory V2.

## First Useful App Outcome
The first app should be useful enough for private sponsor use, while staying small enough to test V3 rather than burying the proof under product scope.

Minimum app direction:
- track health and fitness metrics,
- show trends over time,
- support synthetic data first,
- leave Garmin data integration behind an approved research decision,
- stay internal/private.

## Non-Goals
- Public launch.
- Medical advice, diagnosis, treatment, or regulated health claims.
- Production infrastructure unless separately approved.
- Garmin integration before research approval.
- Hermes use before research approval.
- V2-assisted execution.
